BLACKOUT is a portable hardware security platform built into a PlayStation Portable form factor, designed to interact with, analyze, and experiment with physical and wireless systems. Inspired by multi-purpose devices such as the Flipper Zero, the project combines a compact computing environment with dedicated interfaces for wireless protocols, NFC, infrared, GPIO, and embedded hardware experimentation. The PSP enclosure becomes a purpose-built interface for inspecting signals, interacting with compatible devices, testing communication protocols, and developing custom hardware utilities without carrying a collection of separate tools. The project explores embedded security, wireless protocols, hardware reverse engineering, signal analysis, Linux, microcontroller systems, and portable computing, effectively turning a familiar gaming platform into a general-purpose hardware security instrument.
