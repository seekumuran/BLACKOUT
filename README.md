# PSP: BLACKOUT

> Reimagining the PlayStation Portable as a portable cyberdeck.

## Overview

PSP: BLACKOUT transforms a Sony PlayStation Portable into a compact research platform by replacing its original software stack with a custom Linux-based environment. The project explores how legacy consumer hardware can be repurposed for modern cybersecurity, embedded systems, and networking applications.

## Features

- Linux-based operating environment
- Portable terminal interface
- Wireless networking experimentation
- Embedded systems development
- Custom homebrew applications
- Lightweight cyberdeck experience

## Tech Stack

- Sony PlayStation Portable
- Linux
- C
- Python
- Embedded Linux utilities
